12. PAYMENT INTEGRATION
==================================================

Implement Razorpay payment integration.

Registration Fee:
₹250 per Team

Required flow:

1. Team submits the registration form.
2. Backend validates the submitted information.
3. Backend creates a pending registration.
4. Backend creates a Razorpay order for ₹250.
5. Frontend opens the Razorpay checkout.
6. User completes payment.
7. Backend verifies the payment signature.
8. Backend validates the payment amount and order.
9. Backend updates the registration payment status.
10. Confirmation email is sent after successful
    payment verification.

Use integer paise for Razorpay amounts.

₹250 must be represented as 25000 paise.

Never mark a registration as paid merely because
the browser reports successful payment.

Verify payment server-side.

Implement webhook verification using the configured
Razorpay webhook secret.

Make webhook processing idempotent so repeated
webhook deliveries do not create duplicate payments.

Store payment references and status.

Possible statuses:

- Pending
- Paid
- Failed
- Refunded

Do not store card numbers, CVV values, or other
sensitive payment credentials.

If Razorpay credentials have not been supplied,
implement a clearly marked TEST MODE configuration.

Do not pretend that real payments are active until
the organizer configures valid credentials.

Do not create a fake payment-success screen that
marks users as paid.
